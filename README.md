# Knowledge Base for AI — Frontend

Веб-интерфейс платформы управления корпоративными знаниями ИИ-агента:
база знаний с совместным редактированием, управление сотрудниками,
ролями, пользователями ИИ-агента и журнал событий.

## Стек

* **React 19** + **Vite** — приложение и сборка
* **React Router 7** — маршрутизация с ленивой загрузкой страниц
* **Zustand** — состояние приложения
* **Axios** — HTTP-клиент с автоматическим обновлением токена
* **BlockNote + Hocuspocus (Yjs)** — совместное редактирование тем

## Быстрый старт

```bash
npm install
cp .env.example .env   # укажите адрес backend
npm run dev
```

### Переменные окружения

| Переменная     | Назначение                                  |
| -------------- | ------------------------------------------- |
| `VITE_API_URL` | Базовый адрес backend без суффикса `/api/v1` |

## Команды

| Команда           | Что делает                        |
| ----------------- | --------------------------------- |
| `npm run dev`     | Дев-сервер с горячей перезагрузкой |
| `npm run build`   | Продакшн-сборка в `dist/`          |
| `npm run preview` | Локальный просмотр сборки          |
| `npm run lint`    | Проверка ESLint                    |
