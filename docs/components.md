# Компоненты

## `components/ui/` — примитивы

Не знают про домен и не обращаются к сторам: всё приходит через пропсы.

| Компонент | Назначение |
| --- | --- |
| `Button` | Кнопка: варианты оформления, размеры, состояние загрузки |
| `Input` | Поле ввода с подписью, ошибкой и переключателем видимости пароля |
| `Dropdown` | Выбор одного значения |
| `Multiselect` | Выбор нескольких значений |
| `Filter` | Панель фильтров списка |
| `Toggle` | Переключатель |
| `Spinner` | Индикатор загрузки, он же заглушка `Suspense` |
| `DropdownActions` | Меню действий строки таблицы |
| `ErrorSnackbarStack` | Стек уведомлений об ошибках |
| `SuccessSnackbarStack` | Стек уведомлений об успехе |
| `useErrorWatcher` | Хук, связывающий поля `error` сторов со стеком уведомлений |

## `components/layout/` — каркас

| Компонент | Назначение |
| --- | --- |
| `Layout` | Раскладка страницы: навбар слева, шапка сверху, контент |
| `Header` | Шапка: навигация по правам, профиль, выход |
| `Navbar` | Боковая панель, сворачиваемая на мобильных |
| `NavbarContext` | Контекст и хук `useNavbar` |
| `Table` | Таблица: колонки, сортировка, пагинация, выбор строк |
| `Modal` | Базовое модальное окно |
| `ConfirmModal` | Подтверждение действия |

### Layout и Navbar

`Navbar` управляет своим состоянием сам, но шапке нужна кнопка «открыть меню»
на мобильных. Связь устроена так: `Navbar` передаёт наверх функцию открытия
через колбэк `onOpen`, `Layout` кладёт её в состояние и прокидывает в `Header`.

Функция хранится именно в состоянии, а не в ref: ref нельзя читать во время
рендера, а `Header` получает обработчик именно там.

### NavbarContext

Контекст вынесен в отдельный файл. Файл с компонентом должен экспортировать
только компоненты — иначе ломается Fast Refresh при разработке.

## `components/guards/` — доступ

### `HasPermission`

Показывает содержимое, если у пользователя есть требуемые права.

```jsx
<HasPermission permission="topics.create">
    <Button onClick={openCreate}>Создать тему</Button>
</HasPermission>

<HasPermission permission={['topics.update', 'topics.delete']} mode="some">
    <DropdownActions items={actions} />
</HasPermission>
```

| Проп | Назначение |
| --- | --- |
| `permission` | Строка или массив прав |
| `mode` | `'some'` (по умолчанию) или `'every'` |
| `fallback` | Что показать при отсутствии прав, по умолчанию ничего |

До завершения инициализации профиля возвращает `null`: иначе кнопки
на мгновение пропадали бы и появлялись при каждой загрузке страницы.

## Как добавить компонент

1. Нужен одному экрану → `pages/<page>/components/`.
2. Нужен нескольким и не знает про домен → `components/ui/`.
3. Часть каркаса приложения → `components/layout/`.
4. Стили — рядом с компонентом, имена классов в БЭМ-подобном стиле.
5. Состояние сложнее пары `useState` — выносится в хук рядом с компонентом.
