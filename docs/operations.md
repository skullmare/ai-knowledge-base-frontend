# Эксплуатация

## Требования

* Node.js 20 или новее
* Запущенный backend

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `VITE_API_URL` | да | Базовый адрес backend **без** суффикса `/api/v1` |

Пример — в `.env.example`. Значение подставляется в сборку, поэтому
секретов в нём быть не может: всё, что попадает в `VITE_*`, видно в браузере.

Из этого же адреса строится адрес WebSocket: схема `http` заменяется
на `ws`, добавляется `/api/v1/collaboration`.

## Локальный запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Дев-сервер поднимается на `http://localhost:5173`. Этот адрес должен быть
в переменной `CORS_ORIGINS` на backend, иначе браузер заблокирует запросы,
а refresh-кука не установится.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер с горячей перезагрузкой |
| `npm run build` | Продакшн-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранного приложения |
| `npm run lint` | Проверка ESLint |

## Сборка

`npm run build` выдаёт разделённый бандл:

| Чанк | Когда грузится |
| --- | --- |
| основной | сразу: каркас, роутер, публичные страницы |
| `Topic` | при открытии темы (редактор BlockNote, самый крупный) |
| `Topics`, `Users`, `Logs`, `Profile` | при переходе на соответствующий экран |

Разделение обеспечивает `React.lazy()` в `router/App.jsx`. Новый защищённый
маршрут добавляется тем же способом — иначе его код попадёт в основной бандл.

## Docker

```bash
docker build -t knowledge-base-frontend .
docker run -p 3000:3000 knowledge-base-frontend
```

`VITE_API_URL` задаётся **на этапе сборки** (`ARG`/`ENV` в Dockerfile):
переменные Vite подставляются в код при сборке, менять их в рантайме нельзя.
Для другого окружения нужен новый образ.

## Раздача статики

Приложение — SPA с клиентской маршрутизацией. Веб-сервер обязан отдавать
`index.html` на любой неизвестный путь, иначе прямое открытие `/topics`
или обновление страницы вернёт 404. В образе это делает `serve -s`.

## Типичные проблемы

| Симптом | Причина |
| --- | --- |
| Запросы блокируются CORS | адрес фронтенда не добавлен в `CORS_ORIGINS` на backend |
| Постоянные редиректы на `/login` | refresh-кука не устанавливается: в проде нужен HTTPS |
| Прямое открытие `/topics` даёт 404 | сервер не настроен на fallback к `index.html` |
| Редактор не подключается | `VITE_API_URL` указывает на адрес, недоступный по WebSocket |
| Изменения `.env` не применились | Vite читает переменные при старте — перезапустите дев-сервер |
