## Что это за приложение

Админ-панель платформы корпоративных знаний. Сотрудник входит по логину,
паролю и коду из письма, после чего работает с четырьмя разделами:

* **База знаний** — темы и категории, совместное редактирование, одобрение;
* **Пользователи** — сотрудники платформы, роли платформы, пользователи
  ИИ-агента и их роли;
* **Журнал** — события системы с фильтрами;
* **Профиль** — свои данные, смена пароля, список своих прав.

Всё, что видит пользователь, определяется его правами: маршруты закрыты
`ProtectedRoute`, отдельные кнопки и колонки — `HasPermission`.
