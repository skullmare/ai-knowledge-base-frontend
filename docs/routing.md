# Маршрутизация

Таблица маршрутов — `src/router/App.jsx`.

## Маршруты

| Путь | Доступ | Страница |
| --- | --- | --- |
| `/login` | публичный | Вход по логину и паролю |
| `/verify-2fa` | публичный | Ввод кода из письма |
| `/forgot-password` | публичный | Запрос восстановления пароля |
| `/reset-password/:token` | публичный | Установка нового пароля |
| `/403` | публичный | Нет доступа |
| `/` | сессия | Стартовая страница |
| `/topics` | `topics.read` | База знаний |
| `/topic/:id` | `topics.read` | Редактор темы |
| `/users` | `platformUsers.read` **или** `agentUsers.read` | Пользователи и роли |
| `/logs` | `logs.read` | Журнал событий |
| `/profile` | сессия | Профиль |
| `*` | публичный | Страница 404 |

## Ленивая загрузка

Публичные страницы входят в основной бандл: они нужны сразу и весят мало.
Всё за авторизацией подключается через `React.lazy()` с общим `Suspense`
и спиннером в качестве заглушки.

Причина — редактор BlockNote на странице темы: он больше всего остального
приложения вместе взятого, а нужен одному экрану.

## ProtectedRoute

```
isInitialized === false          → null (ждём восстановления сессии)
нет токена, refresh не пробован  → тихая попытка POST /auth/refresh
refresh не удался                → /login
прав не хватает                  → /403
иначе                            → страница
```

Особенности реализации:

* Попытка обновления защищена ref-флагом: несколько защищённых маршрутов
  в дереве не должны отправить несколько запросов подряд.
* Состояние меняется только в колбэках запроса. Синхронный `setState`
  в теле эффекта запускал каскад лишних рендеров.
* Пока сессия не проверена, компонент возвращает `null`, а не редирект —
  иначе при перезагрузке страницы пользователя выбрасывало бы на `/login`
  до того, как отработает `refresh`.

Параметры:

```jsx
<ProtectedRoute permission="topics.read">          {/* одно право */}
<ProtectedRoute permissions={[...]} mode="some">   {/* хотя бы одно */}
<ProtectedRoute permissions={[...]} mode="every">  {/* все, по умолчанию */}
<ProtectedRoute>                                   {/* только сессия */}
```

## Навигация

Ссылки в шапке (`components/layout/Header`) обёрнуты в `HasPermission`:
пользователь не видит разделов, куда всё равно не попадёт.
